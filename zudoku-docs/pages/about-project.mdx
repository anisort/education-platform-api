# About Project

## Project Overview

The Education Platform API is a RESTful API designed to support an online education platform.

It provides functionality for managing courses, student accounts, and course enrollments. The API allows instructors to manage their courses and students, while students can explore available courses and view their enrollments.

## Main Features

The platform provides the following functionality:

- **User Authentication** — user registration and login using JWT authentication.
- **Course Management** — creating, retrieving, updating, and deleting courses.
- **Student Management** — retrieving information about students enrolled in courses.
- **Course Enrollment** — adding students to courses and removing them from courses.
- **Role-Based Access Control** — restricting operations according to user roles.

## User Roles

The platform supports two user roles:

- **INSTRUCTOR** — manages their own courses and student enrollments.
- **STUDENT** — views available courses and their own enrolled courses.
